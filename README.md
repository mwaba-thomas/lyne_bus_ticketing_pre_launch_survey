# lyne Bus Ticketing App Pre-Launch Survey Analysis

This project contains **SQL-based Exploratory Data Analysis (EDA)** on a pre-launch survey for a bus ticketing app in Zambia.

## In this survey the listed data was analysed

* Customer booking methods
* Preferred payment options
* Popular travel routes
* Booking frustrations
* Desired app features
* Willingness to use the app
* Willingness to pay service fees

## Tools Used

* SQL
* Power BI
* CSV Dataset

## Goal

To discover customer needs, market Demand , and generate business insights before launching the app.
