# Lyne Travel ZM Pre-Launch Survey Analysis

Lyne Travel ZM is a technology company focused on making intercity travel simpler, faster, and more reliable. Today, booking an intercity bus ticket in Zambia is still mostly an offline and frustrating experience. However, the pre-launch survey showed that many travellers are ready for a better and more convenient solution.

This project contains a **SQL-based Exploratory Data Analysis (EDA)** aimed at understanding customer needs, market demand, and generating business insights before the launch of the app.

## The survey data focused on:

* Customer booking methods
* Preferred payment options
* Popular travel routes
* Common booking frustrations
* Desired app features
* Willingness to use the app
* Willingness to pay service fees

## Tools Used

* **SQL** was used to clean, transform, and analyse the data (see the `.ipynb` file).
* **Power BI** was used to create visualizations and dashboards (see the `.pbix` file).
* The **CSV dataset** contains the raw survey data, but it was omitted from this project at the owner’s request.
* A **PDF report** is included, providing a clear narrative summary of the key findings and insights from the analysis.
